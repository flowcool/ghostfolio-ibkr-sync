# Issue tracker: Beads

Issues and specs for this repository live in the shared Beads database. Scope every query and mutation to `project=ghostfolio-ibkr-sync`.

## Conventions

- **List open work**: `bd list --status=open --metadata-field project=ghostfolio-ibkr-sync`
- **Find ready work**: `bd ready --metadata-field project=ghostfolio-ibkr-sync`
- **Read an issue**: `bd show <id>` (text, not `--json`) and `bd comments <id>`
- **Create an issue**: `bd create --title "..." --description "..." --metadata '{"project":"ghostfolio-ibkr-sync"}'`
- **Comment**: `bd comments add <id> "..."`. Triage comments begin with `> *This was generated by AI during triage.*`
- **Apply or remove labels**: `bd update <id> --add-label "<label>"` or `bd update <id> --remove-label "<label>"`
- **Close**: `bd close <id> --reason "..."`

Use Beads issue types as triage categories: `bug` for broken behaviour and `feature` for enhancements. A triage state is represented by exactly one configured label. Mark `wontfix` with that label, add the triage comment, then close the issue.
