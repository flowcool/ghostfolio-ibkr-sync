## Decisions

- **Accept RC in the existing preflight.** `release_metadata` (`scripts/release_image.py:13-20`) accepts either stable (`prerelease` false) or `vX.Y.Z-rc.N` with `N >= 1`, no leading zeros (`prerelease` true). It returns the image tag (`X.Y.Z` or `X.Y.Z-rc.N`). The `release: published` trigger (`release-image.yml:3-5`) fires for prereleases; only the script rejects them.
- **Same build path.** Both jobs reuse native build, scans and digest verification unchanged. `assemble` (`scripts/verify_release_image.py:49-51`) widens its version pattern to allow the `-rc.N` suffix. `registry_version_absent` makes each RC number single-use.
- **No promotion for RC.** The latest step compares the tag with `releases/latest`, which excludes prereleases, so it would skip an RC only by accident. An explicit RC condition makes the skip intentional; the first RC publish proves `:latest` is unchanged.
- **Decision 2: workflow guard, not procedure.** A procedure cannot be checked; the preflight runs with `fetch-depth: 0` and compares `HEAD` to the tag commit (`release_image.py:84-87`). For a stable tag it lists `vX.Y.Z-rc.*` tags, picks the highest `N`, and fails if that commit differs. With no RC, stable stays allowed (hotfix path).
- **Notes.** `.github/release.yml` applies unchanged. RC: `gh release create vX.Y.Z-rc.N --verify-tag --prerelease`. Stable after RC: `--notes-start-tag <previous stable>` so notes cover the whole version; task 3.1 checks them.
- **Renovate.** `renovate.json:17` ignores this image in this repository, so no rule changes here. Consumers: Renovate docker versioning treats the part after `-` as a compatibility suffix and only proposes tags with the same suffix, so a consumer on `X.Y.Z` is not offered `X.Y.Z-rc.N`; `docs/releasing.md` cites that documentation instead of a dry run.
- **Tests.** `release_image.py` decides what reaches the registry, so its RC parsing and stable commit check get offline pytest tests, like the existing release-watch script.
- **Rollback.** Revert the merge commit. Published RC tags stay; later RCs use new numbers.
